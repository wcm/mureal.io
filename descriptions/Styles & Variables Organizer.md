Both variables and styles are supported. Link values used in your design file to all variable and style types quickly, so your design system stays consistent as your product grows.

## Features Overview

### 1) Design Token Cleanup at Scale

- Scan legacy files and identify repeated values across components and pages.
- Merge duplicated styles into a cleaner, easier-to-maintain token system.
- Reduce drift between old screens and current design language.

### 2) Variable Mode Management

- Assess usage by variable modes to understand real adoption.
- Filter variable modes and properties to focus on what needs migration.
- Keep light/dark or brand modes aligned across teams.

### 3) Fast Linking and Bulk Application

- Link selected values to a target style or variable in a few clicks.
- Select all elements using the same value, style, or variable instantly.
- Apply newly created tokens to the entire file without repetitive manual edits.

### 4) Multi-Type Coverage

- Support color, number, and string variables.
- Support color, text, and effect styles.
- Work across a wide range of Figma design system workflows.

## Workflow Tips

### Start with Highest-Impact Values

Focus first on repeated colors, spacing, and radius values.

Example:
`Link all #0F172A values to color variable /text/primary.`

### Migrate Screen by Screen

Apply and verify tokens in one area before scaling to the full file.

Example:
`Migrate onboarding flow first, then dashboard, then settings.`

### Use Modes as a Validation Layer

Check mode-specific usage to catch missing links early.

Example:
`Show components still using fixed values in dark mode.`
